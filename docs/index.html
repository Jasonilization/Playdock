Your whole Steam library, native on your Mac.

Playdock is a controller-first dashboard for the Windows games you run through Wine. Real box art, honest per-game settings, and a "Find best configuration" button for when a title won't behave — all wrapped around your existing Steam account.

Built for the way you actually pick a game

Not a settings panel with games attached — a library you browse like a shelf, with everything controller-friendly and every launch outcome remembered.

🕹️

Controller-first, for real

D-pad and thumbstick navigation across the whole library, focus rings, and on-screen hints — grab a controller off the couch and never touch the mouse.

🖼️

Six layouts, six skins

Grid, Shelves, Sidebar, Steam-style, Carousel, Spotlight — each skinned from Luxury to Terminal — with your real Steam art, ratings, and descriptions.

🧩

Per-game engines, one click

D3DMetal, DXVK, DXMT, MoltenVK per game, remembered forever. Overrides are stored per title, not per hope.

🔎

“Find best configuration”

Pulls real community evidence (AppleGamingWiki + GitHub reports + your own launch history) into a confidence-rated recommendation — never auto-applied.

📦

Your EXEs, welcome too

Drag in any .exe: it gets a card, real metadata discovery, per-game config, and the same launch flow as Steam titles.

🔒

Local-first & quiet

No account, no telemetry. Everything Playdock knows lives on your disk — configs, caches, play sessions, the lot.

A library that treats your art like it matters

Three of the bundled looks. Same real games, same real data — pick whichever surface feels like your setup.

How it fits together

Playdock rides on top of Sikarugir — the same engines Sikarugir Creator downloads — and manages its own dedicated Windows Steam bottle, so your game installs are real Steam installs.

Set up once

A guided wizard downloads a Sikarugir engine and prepares Playdock's own Windows Steam bottle.

Steam login

Sign in once inside the bottle. Your games, art, profile name, and avatar all land on the dashboard.

Click (or tap A)

Launch straight from the beautiful grid — or let Playdock look up which engine is known to work.

Tune per game

Engine, graphics flip-bits, ESYNC — per title, remembered, with local launch history to check them against.

Install in about a minute

Because Playdock isn't notarized yet, macOS will ask you once to confirm you trust it. This is normal for open-source apps distributed outside the App Store.

Option A — Homebrew

  1. brew install --cask jasonilization/playdock/playdock
  2. Launch it from Applications.
  3. If Gatekeeper stops first launch: right-click → Open, or System Settings → Privacy & Security → Open Anyway.

Option B — Download the DMG

  1. Grab the latest Playdock.dmg from GitHub Releases.
  2. Drag Playdock.app to Applications.
  3. Same Gatekeeper step as the left panel, once.
Development pace. Playdock is a student side project: updates ship long-term through its built-in Ship Manager rather than on a fixed schedule — real, tested, small upgrades instead of release-splurges. Feedback and contributions on GitHub are very welcome. 💙

Requirements

  1. macOS 13 “Ventura” or newer, Apple Silicon or Intel.
  2. Sikarugir Creator installed (free) — Playdock guides you if it's missing.
  3. A Steam account with the games you want to play.
